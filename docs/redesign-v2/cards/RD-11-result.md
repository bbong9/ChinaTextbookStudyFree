# RD-11 闯关结算

> 先读 [README](../README.md) 第 1 节全局规则。

**依赖**:RD-05、RD-06、RD-10

## 目标
`LessonResultView` 换成横屏结算页。现有的多幕结构(星级 → 征服 → 护盾 → 连胜 → 里程碑 → 统计 → 任务)保留,第一幕换成设计稿样式,后面各幕改成同一套视觉。

## 设计稿
- [09-result.png](../design/png/09-result.png)

## 范围
### 1. 第一幕:星级 + 收获(合并原 `starsAct` 和 `statsAct`)
- **左侧场景**:旋转光芒、打开的宝箱、彩纸、宠物跳跃(`levelup` 反应)。
- **顶部**:三颗星依次弹出,中间那颗更大;未获得的星是灰色。
- **缎带**:按星级显示「闯关成功!」「真不错!」「完成啦!」。
  - 用词不用「完美」等绝对评价,沿用 UX-12 的约定。
- **右侧「本关收获」卡**,内容来自 `LessonOutcome`:
  - 金币 +N,即 `gemsGained`;
  - 经验 +N,即 `xpGained`,数字滚动增长(沿用 `displayedXp`);周末或挑战翻倍时显示「×2」角标;
  - 等级条:Lv a → Lv a+1 的进度,来自 `levelInfo`。本次升级时,等级条走满后弹出「升级啦!Lv a+1」,宠物播放 `levelup`;
  - 宠物饼干 ×N,即 RD-06 的 `treatsGained`,为 0 时不显示这一行;
  - 识字关卡(RD-13)额外显示「新字卡入册 x / y」。
- **按钮**:「再练一次」(奶油)、「下一关 ▶」(橙)。
  - 有错题时,在两个按钮上方加一行文字按钮「复习刚才错的 N 题」(沿用 `jumpToMistakeReview`)。

### 2. 后续各幕
- 征服、护盾、连胜、里程碑、任务各幕:内容和触发条件不变。
- 每幕统一为「左侧场景 + 宠物」「右侧奶油内容卡」的横屏结构,底部是「继续」按钮。
- 原 `isDarkAct` 的深色幕(连胜火焰)保留深色背景,配色用新令牌。
- 宝箱领取 `ChestModalView` 和分享卡 `ShareCardView`:换成新宠物和新配色,功能不变。

### 3. 升级检测
- 结算时比较课前和课后的 `levelInfo(xp).level`,把结果写进 `LessonOutcome.levelBefore` / `levelAfter`(新字段,在 `completeLesson` 中计算),不要在视图里推导。

## 验收标准
- AC1 iPhone 16 第一幕截图和 09-result.png 对比一致。
- AC2 1 星、2 星、3 星,以及升级、周末翻倍、挑战翻倍、有错题、无饼干,各一张截图。
- AC3 后续各幕各一张截图;每幕都能用「继续」推进,最后回到地图或进入下一关。
- AC4 单元测试:`levelBefore` / `levelAfter` 在跨级、不跨级两种情况下正确。
- AC5 减少动态效果打开时:光芒不转,彩纸不落,星星直接显示。

## 审阅重点
- 幕的推进顺序和触发条件与原实现逐一对照,不能少幕或重复发奖。
