# RD-20 课外书屋

> 先读 [README](../README.md) 第 1 节全局规则。

**依赖**:RD-03、RD-05
**已拍板**:D7,只放书名和自写导读。

## 目标
树洞书屋:按年级推荐课本「快乐读书吧」里的课外书。孩子读的是纸质书;App 只提供自写的导读、读书打卡和每周挑战。

## 范围
### 1. 书单数据 `content/reading-list/books.json`
- 每本书:`{ id, title, author, grade, term, theme, intro, guideQuestions[3], minutes, source, license }`。
  - `intro` 是我们自己写的 100–150 字导读,不摘录原文;
  - `guideQuestions` 是 3 个读书时可以想一想的问题;
  - `source` 写「统编版 X 年级 X 册『快乐读书吧』」;
  - `license` 写 `original`(导读文字是我们自己写的)。
- 范围:一到六年级,每册 2–4 本,约 30 本。书目以统编版各册「快乐读书吧」栏目为准,Codex 整理初稿,审阅时对照目录核对。
- **不放**:正文、真实封面、出版社 logo。封面用 RD-03 的组件生成:渐变书皮 + 书名首字 + 主题小图标。

### 2. 页面 `ReadingRoomView`(Dock「课外书屋」进入;首页地图上的树洞也是这个入口)
- **背景**:木质墙板、圆窗(窗外是树)、右侧书架、木地板;博博(猫头鹰)站在右下角。
- **顶部**:返回;缎带「课外书屋 · 快乐读书吧」;年级切换(一到六年级,默认当前年级)。
- **书架**:3D 书本卡片,每张有书名、阅读进度条和按钮。
  - 没读过的书:按钮是「导读 5 分钟」,打开导读页;
  - 读过的书:按钮是「继续读」,打开打卡页。
- **导读页**:导读文字(TTS 朗读)+ 3 个思考问题 + 「我开始读这本书了」按钮。
- **打卡页**:「今天读了 15 分钟」按钮 + 进度滑块(0–100%,孩子或家长自己填)+ 读完时的「我读完了」按钮。
  - 读完弹出 3 个思考问题,可以选择用录音回答。录音只留在本机,规则同 RD-13「说」。
- **左侧「本周阅读挑战」**:5 个圆点 + 「3/5 天 · 每天 15 分钟」。

### 3. 奖励
- 用 RD-05 的 `readingLogReward` 和 `weeklyReadingChallengeReward`,每天只发一次。
- 「读了 15 分钟」是孩子自报,界面不做真实性校验。家长可以在家长中心关掉书屋奖励(RD-21 的 `readingRewardsEnabled`,默认开);本卡先读取这个设置,没有时视为开。

### 4. 存档
- `readingLog: [String: String]?`(日期 → 书 id)。
- `bookProgress: [String: Int]?`(书 id → 进度百分比)。
- `weeklyReadingBonusClaimed: [String]?`(周键)。
- 同步改两端备份。

### 5. 计时
- 书屋页面本身计入学习时长。读纸质书的 15 分钟不额外计入,避免重复计算。

## 验收标准
- AC1 页面和 19-reading.png 对比一致,附截图。
- AC2 `books.json` 每本书都有 `source` 和 `license`,校验脚本拦截缺失。
- AC3 同一天点两次「读了 15 分钟」只发一次奖励;第 5 天发周奖励(单元测试,和 core 黄金向量一致)。
- AC4 仓库里没有任何书的正文或真实封面图(审阅检查 diff)。
- AC5 导读页 TTS 朗读录屏。

## 审阅重点
- 书目年级是否对得上教材。
- 导读不剧透结局,以激发兴趣为主。
