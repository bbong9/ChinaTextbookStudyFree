# RD-18 成语动画:选择转盘 + 揠苗助长、亡羊补牢

> 先读 [README](../README.md) 第 1 节全局规则。

**依赖**:RD-17

## 目标
做成语的入口页,并用 RD-17 的播放器再上线两个成语。

## 设计稿
- [16-idiom.png](../design/png/16-idiom.png)

## 范围
### 1. 选择页 `IdiomPickerView`(Dock「成语动画」进入)
- **背景**:国风青绿夜色,远处有亭子剪影,下方三层海水纹,描金线。
- **圆形画框转盘**:中间大画框是当前成语,两侧小画框是相邻成语。
  - 左右滑动切换,带吸附;
  - 每个画框里是该成语第一幕的缩略场景,复用 RD-17 的背景和角色绘制,不用位图;
  - 画框下方是木牌标题。
- **成语状态**:
  - 当前:顶部标签「正在学」;
  - 已看过:木牌上有一颗星;
  - 未解锁:灰色加锁。
- **解锁规则**:第 1 个直接可看。之后每看完 1 个,解锁下一个。不花金币。
- 云宝站在中间画框左下方。
- **右上**:「成语册 n」(已看过的成语列表,可以重看)、「收藏」(收藏的成语)。
- 底部提示文字:「左右滑动换成语 · 每个约 2 分钟动画」。

### 2. 成语清单 `content/idioms/index.json`
- 顺序:守株待兔、揠苗助长、亡羊补牢。后续加成语只改这个文件。
- 每一项:`id`、`title`、`order`、`minGrade`(建议年级,只用于排序提示,不限制观看)。

### 3. 两个新成语
- **揠苗助长**(《孟子·公孙丑上》),4 幕:插秧 → 嫌长得慢 → 拔苗 → 禾苗枯了。
- **亡羊补牢**(《战国策·楚策四》),4 幕:羊圈破洞 → 丢了一只羊 → 不听劝又丢 → 修好羊圈。
- 新动作只在 `IdiomActors.swift` 里加,不改播放器。预计需要 `pull`、`wilt`、`fix`、`shake-head`。
- 讲述文字要求同 RD-17:总字数 ≤ 400,PR 附全文。

### 4. 收藏
- `idiomFavorites: [String]?`。同步改两端备份。
- 播放器右上角加收藏按钮。

## 验收标准
- AC1 选择页和 16-idiom.png 对比一致,附截图。
- AC2 3 个成语都能完整播放(各一段录屏)。
- AC3 解锁规则有单元测试。
- AC4 播放器文件在本 PR 里没有改动,或者改动有说明理由。
- AC5 VoiceOver 下可以用「上一个 / 下一个」切换成语。

## 审阅重点
- 亡羊补牢的结尾要落在「及时改正就不晚」,不要变成说教。
