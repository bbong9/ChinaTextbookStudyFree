# RD-09 首页闯关地图

> 先读 [README](../README.md) 第 1 节全局规则。

**依赖**:RD-01、RD-03、RD-04、RD-05 · **不要和 RD-22 并行**(都改 `MainShell` / `HomeView`)

## 目标
用横屏大场景地图替换现在的竖向路径首页。课程节点数据沿用 `PathNodeBuilder`,只换展示层;现有首页的全部功能都要在新首页找到入口。

## 设计稿
- [02-map.png](../design/png/02-map.png)

## 范围
### 1. 地图(新 `Features/Home/MapHomeView.swift`)
- **横向滚动**。场景按设计稿分层(用 RD-03 组件):
  - 天空和远山:视差 0.3;
  - 中景:蘑菇屋、灌木、小火车轨道,视差 0.6;
  - 小路和字块:视差 1.0;
  - 前景:草丛,视差 1.1。
- 场景**按单元分段**。每个单元一段宽约 844 的场景,单元之间放一块木牌写「第 N 单元 · 单元名」。每段背景元素从组件库里按单元序号确定性地挑选和排列,不要求每段都不同,但相邻两段不能完全一样。
- 小路:`PathRoad`,节点沿一条平滑波浪线排布,间距约 62(设计稿 `pts`)。
- **节点 → `CharCube`**:
  - `lesson` 节点:标签是该节点在本书里的序号(Nunito 数字);状态用 `status`(done / current / locked),done 显示星级;
  - `chest` 节点:换成 `GiftView`,上面挂「宝箱」蓝色小标签;已领取的变半透明;
  - `exam` 节点:换成紫色 `game` 方块,标签「挑战」;已征服的显示金色奖杯角标;
  - **识字关卡**(RD-13)出现在语文书里时,标签是那个汉字(楷体)。
- 出战宠物站在当前节点上方(`PetView`,`bob` 动画)。
- 进入首页时自动滚到当前节点,当前节点位于屏幕横向约 40% 处。滚远以后右侧出现「回到当前」按钮(复用现有逻辑)。
- **点节点**:
  - 弹出开始气泡,内容是课程标题、单元名、+XP;点「开始」进入关卡(沿用 `startPopup` 的逻辑);
  - 点锁定节点:宠物摇头 + 提示;
  - 点锁定单元的木牌:出现「⚡ 跳到这里」入口,通往 `jumpTest`;
  - 点已解锁单元的木牌:出现「单元手册」入口,通往 `guide`。

### 2. HUD
- **左上**:
  - 头像 `AvatarBadge`:出战宠物 + Lv,Lv 来自 `levelInfo`。点击打开头像菜单,菜单项:我的、成就墙、排行、错题本、设置;
  - 金币 `StatPill`:点击打开原「宝石」详情,改名金币;
  - 连签 `StatPill`:点击打开原 `StreakDetailSheet`,护盾和补卡功能保留。
- **顶部中间**:「今日目标」条,内容是 今日 XP / 每日目标 + 金币图标;达标后变绿并显示 ✓。
  - 当前书是识字书且已进入识字模式时,改为「今日识字 x / y 字」。y 来自家长中心「识字速度」(RD-21),RD-21 之前默认 5。
- **红心**:新增一个红心 `StatPill`,放在连签右边。点击打开原 `HeartDetailSheet`。0 心时仍然弹出原来的提示。
- **右上**:签到(有可领时显示红点)、宠物店、任务、家长。
  - 任务:新面板 `quests`,内容是现有 `DailyQuestsCard` + 错题复习入口 + 本周报告(`WeeklyReportCard`),改成奶油卡片风格;
  - 家长:进家长门(RD-21),RD-21 之前直接进设置。
- **左下**:书本徽章「部编版 / 人教版 + 一年级上」。文字取当前书的 `fullName` 缩写。点击打开原 `BookPickerSheet`,本卡把它改成横屏双栏样式。
- **底部 Dock**:7 个入口——识字游戏、数学火车、英语气球、看图识物、故事绘本、成语动画、课外书屋。图标用 `DockIcon`,文字用 `OutlinedLabel`。
  - 没有数据的入口(例如当前书没有识字包)不隐藏,点击后提示「这本书还没有识字关卡,换一本语文书试试」。
- **右下**:`GoButton`「闯关」,直接开始当前节点的课程。

### 3. 场景里的地标(可点击)
- 蘑菇屋 → 宠物小屋;
- 树洞(地图最左端的大树)→ 课外书屋;
- 小火车 → 数学小火车。
- 这三处在每个单元段里只出现一次,出现在第 1 单元段。

### 4. 必须保留的现有首页功能
- 书没下载时显示 `BookDownloadCard`:改成场景中间一块奶油色木牌,样式统一,下载逻辑不变。
- 空状态 `emptyState`(没有选书)。
- 宝箱节点的 `ChestModalView` 全屏领取。
- 首页的每日奖励弹卡 → 改为 RD-08 说的小气泡;RD-08 未合并时保留原弹卡。
- 课文听读、故事入口(原来的 `sideEntry`)→ 并入 Dock「故事绘本」(RD-19)。RD-19 之前,Dock 的「故事绘本」先进原来的 `stories` / `reading` 路由。
- 云端存档恢复提示,本地联赛结算弹幕,这些现在挂在首页的弹层都要保留。

### 5. 替换
- `MainShell` 的根页面换成 `MapHomeView`。
- 旧 `HomeView`、`PathMapView` 在本卡删除。可以复用的逻辑(`PathNodeBuilder`、滚动定位、宝箱判断)搬到新文件或保留成独立类型。

## 验收标准
- AC1 iPhone 16 上首屏和 02-map.png 对比:结构、层级、HUD 位置一致。附对比图。
- AC2 iPhone SE、iPhone 16 Pro Max、iPad 截图:HUD 贴边,Dock 不挤压、不重叠,文字不截断。
- AC3 第 4 节每项功能各附一张截图或 UI 测试证明仍可用。
- AC4 UI 测试 `MapHomeUITests`:启动 → 当前节点可见 → 点「闯关」进入关卡 → 返回 → 点头像菜单进错题本 → 返回 → 点书本徽章能换书。
- AC5 一本 30+ 节课的书,地图来回快速滑动不卡顿(附 FPS 证据);长书首屏打开时间不超过旧首页 + 20%(PR 里附两次测量)。
- AC6 减少动态效果打开时:无视差、无浮动,滚动定位仍然正常。

## 审阅重点
- 节点和关卡的对应关系、解锁规则完全复用 `PathNodeBuilder`,不能在视图层重新推导。
- 所有入口都有 `accessibilityIdentifier`;Dock 七项用 `dock-<kind>`。
