## 范围
### 1. 宠物家族 `petFamily`(图鉴)
- 按设计稿布局:草地 + 一排石台,每个石台上一只宠物,下面是名牌(名字、获得方式、技能)。
- 共 10 个位置:7 只主宠物 + 3 只蛋系宠物。蛋系的位置在未孵出前显示问号蛋剪影。
- 未拥有的宠物:灰色剪影(对应 `f-gray` 滤镜:去饱和,透明度 .55),名牌显示获得条件。
- 点任意宠物:已拥有 → 进小屋并切换出战;未拥有 → 进商店并选中它。
- 入口:小屋右上角「图鉴 x/10」。

### 2. 宠物商店 `petShop`
- 左侧聚光灯展示选中宠物(大尺寸 + 呼吸动画),下面是名字、一句介绍、技能,以及「领养」按钮(金币图标 + 价格)。
- 右侧两层货架,6 个位置:阿橘、奶糖、冰冰、博博、云宝、神秘蛋。价签用单行白色胶囊(名字 + 价格或条件);选中的价签变橙色。
- 顶部:返回、「宠物商店」缎带、金币余额。
- 状态:
  - 可领养 → 橙色按钮可点;
  - 金币不足 → 按钮置灰,显示「还差 N 金币」;
  - 条件未达成(博博、云宝)→ 灰色剪影 + 锁 + 条件文字,按钮文字是条件(例如「Lv10 解锁」);
  - 已拥有 → 「已领养 · 去看看」;
  - 神秘蛋售完 → 「已孵完」。
- **领养确认**:弹出确认框「花 450 金币领养阿橘?」,确认后播放庆祝动画(复用现有 `ConfettiView`)。
- **神秘蛋**:确认后进全屏孵化动画:蛋晃 3 次 → 裂纹 1、2、3 → 破壳 → 新宠物跳出来 + 名字缎带。
- 现有 `ShopView` 的「护盾、补满红心」两个功能道具保留,放到商店底部的「道具」小货架,样式统一成新风格。主题、背景两类装扮在本卡下架(见下文「不做」)。
- 配饰(旧皮肤)在小屋的「装扮」里卖,不放在商店。

### 3. 宠物小屋 `petHome`
- 场景按设计稿:暖色墙面 + 圆点墙纸、木地板、窗户、窗帘、小盆栽、相框里的蛋、地毯、宠物窝、食盆、球。
- 中间是出战宠物,大尺寸,带呼吸动画,点一下有反应。
- 左上:返回、金币。正中:名牌,包含名字、Lv、经验条、「再得 N 经验 → 下一形态」。目前只有米团有形态变化(Lv5 开花),其他宠物显示「再得 N 经验 → Lv{n+1}」。
- 左下:三个状态条(开心、饱饱、干净),数值来自 RD-06。
- 右下:四个动作按钮。
  - 喂食:角标显示饼干数;动画是饼干飞到宠物嘴里。
  - 洗澡:泡泡动画;冷却中显示剩余时间。
  - 玩耍:球弹跳,宠物跟着跳;冷却中显示剩余时间。
  - 装扮:打开配饰抽屉,显示已拥有 / 可购买的配饰,价格沿用原皮肤价格。
- 宠物气泡台词根据照顾状态和今日学习情况变化,至少 6 条,例如「今天学了 3 节课,我好开心!」「肚子饿啦」。
- 右上:「图鉴 x/10」「宠物店」。
- 左右滑动或点两侧箭头可以切换已拥有的宠物,切换即设为出战。

### 4. 入口与文案
- 首页的蘑菇屋和顶部「宠物店」入口在 RD-09 接线。本卡先确保路由可用。
- 全 App 文案中的「聪聪」改为出战宠物的名字(RD-04 临时写死的「米团」也一起改掉)。

## 不做
- 主题、背景装扮下架。已拥有的保持生效,设置里仍可切换,但商店不再售卖。PR 里要写明这一点。见 README 第 5 节 D8。
- 图鉴里的宠物故事页。

## 验收标准
- AC1 三个页面和设计稿对比(iPhone 16),结构、层级、配色一致。附对比图。
- AC2 商店 5 种状态(可领养、金币不足、条件未达、已拥有、售完)各一张截图。
- AC3 神秘蛋孵化完整流程录屏(.mov 或 GIF),孵出顺序正确。
- AC4 喂食后饼干 −1、饱饱上涨;冷却期间洗澡/玩耍按钮不可点并显示倒计时。
- AC5 切换出战宠物后,首页、课程、结算页显示的都是新宠物。
- AC6 UI 测试:领养一只宠物(测试开局给足金币,通过启动参数注入),断言余额减少、宠物出现在小屋可切换列表里。

## 审阅重点
- 领养、孵化的按钮是否防连点(只扣一次钱)。
- 灰色剪影对比度是否足够让孩子看出是什么动物。
