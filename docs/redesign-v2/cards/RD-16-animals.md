# RD-16 幼儿看图识物(动物、水果、交通、身体)

> 先读 [README](../README.md) 第 1 节全局规则。

**依赖**:RD-03、RD-04 · **可并行**:RD-14、RD-15、RD-17、RD-19

## 目标
面向 3–6 岁:在场景里点一点,听名字和声音,收集图鉴。没有对错,没有分数,没有奖励。

## 设计稿
- [15-animals.png](../design/png/15-animals.png)

## 范围
### 1. 数据 `Domain/PictureWords.swift`(静态数据,写在代码里)
- 每个词条:`id`、`char`(1–2 个汉字)、`pinyin`、`english`、`sound`(例如「咩咩」,没有叫声的写一句短介绍)、`art`(clay 或 emoji)。
- **4 个分类,共 50 条**:
  - 动物 20;
  - 水果 10;
  - 交通工具 10;
  - 身体部位 10。
- 动物里有 7 种用黏土造型:小黄鸭、猪、羊直接用 `PetView` 的 duck、pig、sheep;狐狸、猫、企鹅、猫头鹰用 `PetView` 的 fox、cat、penguin、owl。其余用 emoji。
- 拼音、英文、叫声要人工核对。PR 里附整张表。

### 2. 界面
- **顶部**:返回、「看图识物 · 3–6 岁」绿色缎带、分类切换(4 个圆形图标按钮)。
- **动物分类**:3 个场景左右滑动切换,词条按栖息地分到 3 个场景里。
  - 农场:设计稿场景,红色谷仓、栅栏、小池塘;
  - 森林;
  - 水边。
- **其他分类**:用简单的背景(果园、马路、镜子房),物品散布在场景里。
- 点一个物品:
  - 物品身后出现光晕,轻轻弹一下;
  - 右侧弹出字卡:大字(楷体)+ 拼音 + 英文 + 叫声;
  - 自动朗读「羊,yáng」,再读叫声。英文不自动读,字卡上有单独的喇叭按钮。
- 场景提示文字:「点一点小动物,听它的名字和叫声」。
- **图鉴**:右下角「图鉴 6 / 50」。点过的词条记入图鉴,图鉴页是网格,未点过的显示剪影。
- **字号**:大字至少 72pt,拼音至少 24pt。
- 所有可点物品 ≥ 64×64pt(按幼儿手指放大)。

### 3. 存档与计时
- `pictureWordsSeen: [String]?`。同步改两端备份。
- 本页计入学习时长。

## 验收标准
- AC1 动物农场场景和 15-animals.png 对比一致,附截图。
- AC2 4 个分类、3 个动物场景各一张截图。
- AC3 50 个词条的数据表(拼音、英文、叫声)附在 PR 里,供审阅逐条核对。
- AC4 图鉴计数正确,重启 App 后不丢。
- AC5 VoiceOver 下每个物品都能读出名字。

## 审阅重点
- 不出现任何「答错」反馈,这是幼儿探索模式。
