# RD-13 识字五步关卡(玩认练写说 + 字源卡)

> 先读 [README](../README.md) 第 1 节全局规则。

**依赖**:RD-09、RD-11、RD-12;RD-05 的 `hanziLessonXp`

## 目标
每个汉字一关,按「玩 → 认 → 练 → 写 → 说」五步学完。入口是首页 Dock 的「识字游戏」:打开该书的识字地图,复用 RD-09 的地图组件,字块显示汉字。

## 范围
### 0. 识字地图 `hanziMap(bookId:)`
- 复用 RD-09 的地图组件。节点 = `index.json` 里的字,按单元分段;每 4 个字后插一个宝箱节点(复用现有宝箱逻辑和奖励)。
- **解锁规则**:顺序解锁,完成上一个字解锁下一个字。
- 「今日目标 x / y 字」:x = 今天完成的字数,y = 识字速度(RD-21,默认 5)。
- 完成状态存档:`hanziProgress: [String: HanziResult]?`,key 为 `"{bookId}:{char}"`。`HanziResult` 包含 `stars`、`completedAt`、`steps`(已完成的步骤集合)。同步改两端备份。

### 1. 关卡通用 HUD(所有步骤共用)
- 左上:返回。
- 中:`StepBar`「玩 认 练 写 说」。已完成的步骤可以点击回看;未到的步骤不能跳过去。
- 右上:「古」(有 `origin` 时才显示)、帮助、暂停。「写」这一步把帮助换成重写。
- 左下 / 右下:上一步 / 下一步圆按钮。当前步骤完成后,「下一步」才亮起。
- 中途退出:保存已完成的步骤,下次从第一个未完成的步骤继续。

### 2. 玩:喂宠物(03-l0)
- **场景**:草地、树、小屋;宠物居中;下方奶油色大盘子,盘子上 3 个包子,每个包子上写一个字(目标字 + 2 个形近或同音干扰字)。
- 宠物气泡:「我饿啦,想吃 [🔊 shān]」,进入时自动朗读一次。
- **操作**:把正确的包子拖到宠物嘴边。也支持直接点击包子,作为无障碍替代操作。
  - 对:宠物吃掉包子,播放 `correct` 反应;
  - 错:包子弹回原位,宠物摇头,再读一遍。
- 3 题,左下角显示「第 n/3 题」。每题干扰字从 `distractors` 里随机取,随机种子固定为 字 + 日期。
- 首次就答对的题数计入 `firstTryCorrect`。

### 3. 认:看图识字(04-l1)
- 紫色渐变背景,背景里是本单元其他字的淡水印。
- **左**:看图卡,显示 `scene` 对应的插画,插画上用橙色虚线勾出字形;下方标签是 `sceneCaption`。`scene` 为 null 时,显示放大的组词卡代替。
- **中**:田字格大字,用 `strokes.outline` 绘制,不用字体渲染;上方是拼音牌,右下角是朗读按钮。
- **右**:2–4 个组词按钮,点击朗读。
- 宠物在下方。全部组词点过一遍,或停留 8 秒后,本步完成。
- **场景插画**:本卡要为试点里的象形字画场景插画(RD-12 `scene` 字段用到的那些 id,预计 8 个左右:日、月、水、火、山、石、田、禾),用 RD-03 的组件和渐变绘制。

### 4. 练:跳石头过河(06-l2)
- **场景**:河、两岸、3 块石头,每块石头上一个字;对岸有宝箱;宠物在左岸。
- 提示条:「🔊 听一听,跳到 shān 的石头上」。
- **操作**:点石头。
  - 对:宠物沿虚线弧线跳到石头上,再跳到对岸;
  - 错:石头晃一下沉下去再浮起来,重读一遍。
- 3 题,右上角显示 3 颗星的进度。干扰字规则同「玩」。

### 5. 写:笔顺描红(07-l3)
- 绿色渐变背景,背景里是拼音水印。
- **中**:290pt 田字格。已写的笔画是深色;当前笔画显示浅色描红底 + 起笔星星。
- **右**:笔顺列表「笔顺 · N 画」,高亮当前笔画。
- **左**:宠物 + 3 个果子。写对一整遍点亮一个果子,3 个果子都亮了本步完成。
- **示范**:每一遍开始前,手指沿当前笔画演示一次(动画时长参照设计稿 3.2 秒的节奏)。帮助按钮可以重放示范。
- **判定**(`Domain/StrokeMatcher.swift`,纯函数,必须有单元测试):
  - 把手指轨迹和 `median` 都重采样为 32 个点,在 1024 坐标系下比较;
  - 平均点距 < 阈值 A(默认 160),起点距离 < 阈值 B(默认 200),整体方向夹角 < 45°,三项都满足才算对;
  - 阈值放常量,写测试覆盖:正确、反向、写成别的笔画、太短、偏离太多;
  - 对:笔画变深色并固定,进入下一笔;
  - 错:轨迹变红后淡出;连续错 2 次,自动播放示范。
- 支持手指和 Apple Pencil。笔画宽度随设备缩放。
- **兜底**:D5 已定,试点字都应该有笔顺。万一某个字的 `strokes` 为空,本步显示「写字功能准备中」,并自动视为完成,但不计「写」的 XP。

### 6. 说:小舞台跟读(08-l4)
- **场景**:舞台、红幕布、木地板;宠物拿话筒;中间字卡(大字 + 拼音 + 组词)。
- **操作**:按住红色录音键录音(最长 5 秒),松开后:
  1. 播放标准读音;
  2. 播放孩子自己的录音;
  3. 宠物气泡「读得真棒!」+ 3 颗星。
- **不做发音评分**。星星表示完成跟读,不表示发音准确度。文案不出现「准确」「得分」。
- 录音只存在临时目录,离开本步立即删除,和现有课文跟读的隐私承诺一致。
- 麦克风权限复用现有说明文案。孩子拒绝权限时,本步改为「听一听,跟着读一遍」,点「我读完了」完成。
- 复用 `PassageReaderView` 已有的录音实现,不要再写一套。

### 7. 字源卡(05-gu)
- 点「古」打开:暗色蒙层 + 白卡。
- `origin.forms` 非空时:显示「甲骨文 → 金文 → 小篆 → 楷书」时间轴。楷书一栏用 `strokes.outline` 绘制。
- `origin.forms` 为空时(D6 的第一版情况):只显示楷书大字 + `kind` + `explanation`。
- 底部「听字源小故事」按钮,播放 `audio.origin`;没有录音时用系统 TTS 朗读 `explanation`。

### 8. 结算
- 五步都完成后进入 RD-11 结算页。XP、星级、金币按 RD-05 第 7 节计算。结算页额外显示「新字卡入册 x / y」,y 为本书识字总字数。
- **字卡册**:地图右上角加入口,网格展示已学的字。点击一个字可以再听读音、看笔顺动画。

## 验收标准
- AC1 五步 + 字源卡在 iPhone 16 上和设计稿各自对比一致,附 6 张对比图。
- AC2 完整走完「山」一个字的录屏(.mov 或 GIF),中途退出再进入能从断点继续。
- AC3 `StrokeMatcherTests` 覆盖第 5 节列出的全部情形。
- AC4 「玩」和「练」都有点击替代拖拽的方式,VoiceOver 能完成这两步。
- AC5 拒绝麦克风权限时,「说」仍然能完成。
- AC6 识字结算的 XP 和金币与 RD-05 的黄金向量一致(单元测试)。
- AC7 `strokes` 为空的字能走完五步,不崩溃。

## 审阅重点
- 干扰字的随机种子固定(同一天同一字题目一致),方便复现问题。
- 「写」的判定阈值在 iPhone SE 和 iPad 上都实际试过。PR 里写明试写结果:写对多少次被判错,写错多少次被判对。
