# RD-17 成语动画:播放器 + 守株待兔

> 先读 [README](../README.md) 第 1 节全局规则。

**依赖**:RD-03、RD-05 · **可并行**:RD-14、RD-15、RD-16、RD-19

## 目标
做一个通用的「成语短动画」播放器,并用它做出第一个成语《守株待兔》。动画用 SwiftUI 矢量场景加关键帧,不用视频文件。每个成语约 2 分钟。

## 范围
### 1. 剧本格式(数据驱动,不要把剧情写死在视图里)
- `content/idioms/<id>.json`:
```
{
  "id": "shou-zhu-dai-tu", "title": "守株待兔", "pinyin": "shǒu zhū dài tù",
  "meaning": "比喻死守经验、不知变通,也比喻想不劳而获。",
  "source": "《韩非子·五蠹》", "license": "original",   // 原文是公版,讲述文字和画面是我们自己写的
  "scenes": [
    { "chapter": "种田", "durationHint": 25,
      "backdrop": "field", "actors": [{ "id": "farmer", "pose": "hoe", "x": 0.32 }],
      "beats": [ { "at": 0, "subtitle": "从前,宋国有个农夫……", "audio": "/audio/…", "actions": [{ "actor": "farmer", "do": "hoe" }] } ] }
  ],
  "quiz": [ { "prompt": "农夫最后得到了什么?", "options": ["很多兔子","一片荒地","一棵大树"], "answer": 1 } ]
}
```
- 一个成语分 4 幕(`chapters`),每幕有若干节拍(`beats`)。每个节拍包含:字幕、配音、角色动作。
- **节拍推进以配音为准**:配音播完才进入下一个节拍。没有配音时用系统 TTS,读完再推进。不用固定秒数,避免字幕和声音对不上。
- 角色动作是一个有限集合,由 `IdiomActors.swift` 实现。第一批:`hoe`(锄地)、`run`(兔子跑)、`bump`(撞树)、`pick`(捡起)、`sit`(坐着等)、`sleep`(打盹 zzz)、`sigh`(叹气)、`weeds`(杂草长高)。
- 场景背景(`field`、`field-weedy` 等)用 RD-03 组件绘制,参考设计稿 `idiomArt`。

### 2. 播放器 `IdiomPlayerView`
- **顶部**:返回;标题缎带「守株待兔 · 3/4」;章节进度条(4 段:已看过、当前、未看);暂停。
- **底部**:字幕条,当前句逐字高亮,和配音同步。
- **右侧**:「成语小卡」,写释义和出处。默认收起,第 4 幕结束后自动展开。
- **操作**:
  - 点章节可以跳到已看过的幕;
  - 暂停时显示「继续 / 重看本幕」;
  - App 切到后台自动暂停。
- 结尾 1 道小问答(剧本里的 `quiz`),答对答错都只给鼓励,不扣红心。
- 第一次完整看完(播到最后一个节拍并且答完问答)发放 RD-05 的 `idiomFirstWatchReward`。
- 出战宠物是云宝时,片头加一句云宝解说。台词写在剧本里的可选 `intro.yunbao` 字段。

### 3. 第一个成语:守株待兔
- 4 幕:种田 → 兔撞树 → 天天等 → 田荒了。
- 讲述文字由 Codex 写初稿,口语化,适合 6–8 岁,总字数 ≤ 400。PR 附全文供审阅。
- 配音走现有 `scripts/tts/` 管线生成,登记进 `SpeechTextIndex`。

### 4. 存档
- `idiomsWatched: [String: String]?`(成语 id → 首次看完日期)。同步改两端备份。
- 本页计入学习时长。

## 验收标准
- AC1 播放画面和 17-idiomplay.png 对比一致,附截图。
- AC2 完整播放录屏(带声音),字幕和配音同步。
- AC3 剧本 JSON 有 schema 校验(TS 端 `idiom.ts` 定义类型 + 测试),非法动作名会报错。
- AC4 第二次看完不再发奖励(单元测试)。
- AC5 减少动态效果打开时,角色动作改成淡入淡出切换,字幕和配音照常。

## 审阅重点
- 播放器和剧本的边界:RD-18 再加两个成语时,只加 JSON 和少量新动作,不改播放器。
- 讲述文字的价值观:准确传达寓意,不嘲笑人物。
