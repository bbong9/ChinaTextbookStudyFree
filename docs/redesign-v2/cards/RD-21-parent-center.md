# RD-21 家长中心与家长门

> 先读 [README](../README.md) 第 1 节全局规则。

**依赖**:RD-02、RD-08

## 目标
把家长相关的设置和报告集中到一个家长中心,入口在首页右上角「家长」。进入前要过一道家长门(一道算术题),防止孩子误入。

## 范围
### 1. 家长门 `ParentGateView`
- 弹层,题目是两位数乘一位数,例如「12 × 3 = ?」。随机出题,用数字键盘输入。
- 答错:换一题。连续错 3 次后锁 60 秒。
- 通过后 5 分钟内再进家长中心不用重答,只在内存里记,重启 App 失效。
- 现有设置页里的「导入备份」「清除数据」这类危险操作,入口也加家长门。
- 题目不朗读,无障碍标签正常提供。

### 2. 家长中心 `ParentCenterView`
- **布局**:
  - 天蓝渐变背景加云朵;
  - 顶部 5 个彩色标签:学习设置 / 学习报告 / 时间管理 / 数据与备份 / 关于;
  - 设计稿第 4 个标签写的是「账户」,但本 App 没有账户体系,改名为「数据与备份」;
  - 左侧是设置面板,右侧是本周报告卡。宽度不够(SE)时,报告卡挪到「学习报告」标签里。
- 面板内用普通 SwiftUI 布局,支持动态字体到 `xxLarge`(全局规则 1.2)。

#### 学习设置
| 设置 | 选项 | 存储 | 说明 |
| --- | --- | --- | --- |
| 每日学习时长 | 15 / 20 / 30 / 45 分 | `SettingsStore.dailyMinutesGoal`,默认 20 | 只用于首页提示和报告。学习时长宝箱的 10/20/30 分档不随它变 |
| 每日 XP 目标 | 20 / 50 / 100 / 200 | 现有 `UserProgress.dailyGoal`(进备份) | 从「我的」页搬过来,逻辑不变 |
| 识字速度 | 5 / 10 / 15 字/天 | `SettingsStore.hanziPerDay`,默认 5 | RD-09、RD-13 读取 |
| 护眼提醒 | 开关 | RD-08 的 `eyeCareReminder` | 文案「每 20 分钟休息一下」 |
| 教材版本与年级 | 跳转 | 现有选书流程 | 显示「统编版 · 一年级上」 |
| 宠物商店消费 | 开关 | `SettingsStore.petShopEnabled`,默认开 | 关掉后商店只能看不能买,按钮显示「家长已关闭购买」。副标题「只能用学习金币,无真钱购买」 |
| 书屋打卡奖励 | 开关 | `SettingsStore.readingRewardsEnabled`,默认开 | RD-20 读取 |

- 这些都是本机设置,**不进** `UserProgress`、不进备份,和现有 `SettingsStore` 字段一样处理。如果现有 `SettingsStore` 里已经有字段要进备份,按它的规则处理,并在 PR 里说明。

#### 学习报告
- 本周 KPI:新认字数(来自 `hanziProgress`,没有识字数据时显示「完成课程数」)、平均每天分钟数(来自 RD-08 的 `studySeconds`)、正确率(本周课程正确率,数据来源在 PR 里说明)。
- 7 天柱状图:每天学习分钟数,今天的柱子用金色。
- 易错字或易错知识点:错题本里本周错次最多的 2 项。
- 现有的周报(如果首页任务里有周报入口)指向这里,不要做两套。

#### 时间管理
- 每日时长上限:关 / 30 / 45 / 60 分。到上限时弹出温和的休息页「今天学得够多啦」,家长输入家长门题目可以继续。默认关。
- 可用时段:例如 21:00 以后不能开始新的闯关。默认关。
- 现有的学习提醒(通知时间)从设置页搬到这里。

#### 数据与备份
- 现有设置页的导出、导入、清除数据功能搬到这里,逻辑不变。

#### 关于
- 版本号、开源许可、内容来源说明(包括 RD-12 的第三方数据许可证)。

### 3. 设置页瘦身
- 孩子能直接进的设置页只保留:外观、音效和触感、关于。其余项移到家长中心。
- 「我的」页上的每日目标卡片仍然显示进度,但不能改档位。

## 验收标准
- AC1 家长中心和 20-parent.png 对比一致(iPhone 16),附截图;SE 截图里报告卡不挤压设置面板。
- AC2 家长门:答错换题、连续错 3 次锁 60 秒、5 分钟内免答,有单元测试。
- AC3 关掉宠物商店消费后,商店不能购买(UI 测试)。
- AC4 时长上限到了会弹出休息页(用启动参数注入今天的学习秒数来测试)。
- AC5 搬家后的导出、导入、清除数据和原来的行为一致(手测记录)。
- AC6 动态字体 `xxLarge` 下的截图。

## 审阅重点
- 设置项搬家时不能丢已有值:老用户升级后,每日目标、提醒时间保持原值。
- 时长上限是提醒,不是惩罚:休息页没有倒计时惩罚,也不扣任何东西。
