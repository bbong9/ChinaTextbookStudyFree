# RD-14 数学小火车

> 先读 [README](../README.md) 第 1 节全局规则。

**依赖**:RD-03、RD-05 · **可并行**:RD-15、RD-16、RD-17、RD-19

## 目标
口算小游戏。车头举着算式,3 节车厢上写着候选答案,点对的车厢挂到火车上。答对 10 题,火车到站。

## 范围
### 1. 题目生成 `Domain/MathTrain.swift`(纯函数,带种子)
- 题目难度按当前数学书的年级和册次取档。没有数学书时,按 `selectedGrade` 取档。

| 档位 | 题型 |
| --- | --- |
| 一上 | 10 以内加减;后半程 20 以内进位加、退位减 |
| 一下 | 100 以内整十加减;两位数加减一位数 |
| 二上 | 100 以内加减(含进退位);2–6 的乘法口诀 |
| 二下 | 表内乘除(口诀 2–9);万以内整百整千加减 |
| 三年级 | 两三位数加减;两位数乘一位数;表内除法 |
| 四年级及以上 | 三位数乘一位数;整十整百的乘除;简单的四则混合(两步) |

- 每题 3 个选项,其中 2 个干扰项:±1、±10、或者用错运算符得到的结果。干扰项不能和正确答案相同,也不能是负数。
- 随机数用种子,种子 = 日期 + 局数。core 里已有 `rng.ts`,Swift 侧写一个同算法的实现,保证可复现。
- 单元测试覆盖:每个档位生成 1000 题,答案都正确、选项不重复、不出负数。

### 2. 界面
- **场景**:草地 + 铁轨 + 枕木(`TrainView`),车头上有冒烟动画;出战宠物坐在车头里。
- **顶部**:返回;算式板「8 + 5 = ?」;用时(正计时,只显示,不扣分);连对次数「🔥 连对 ×4」。
- **3 节候选车厢**:从右侧开进来停在轨道上,每节车厢上写一个答案。
  - 点对:车厢挂上火车,火车往前开一小段;
  - 点错:车厢摇一摇变灰,不能再点。
- 第一次就点对才算这题答对;每题必须点对才能进入下一题。
- 10 题后火车进站:站台、彩纸、本局成绩(正确率、用时、最佳用时),以及 RD-05 的奖励。今天的奖励局数用完时显示「今天的奖励领完啦,还可以继续练习」。
- **提示**:每局 1 次提示,出战宠物是阿橘时 2 次。提示的效果是去掉一个错误答案。
- 不扣红心,不计入错题本。

### 3. 存档
- `miniGameStats: [String: MiniGameDayStats]?`(日期 → 统计),`MiniGameDayStats` 包含每个游戏的已奖励局数。
- `mathTrainBest: [String: Int]?`(档位 → 最佳用时秒数)。
- 只保留最近 7 天的日统计。同步改两端备份。

### 4. 计时
- 本页计入学习时长(RD-08)。

## 验收标准
- AC1 页面和 13-math.png 对比一致(iPhone 16),附截图。
- AC2 题目生成器单元测试(见第 1 节)通过。
- AC3 一局完整录屏:含点错、用提示、到站结算。
- AC4 第 4 局不发奖励,并显示说明(用启动参数注入已玩 3 局来测试)。
- AC5 阿橘出战时提示次数为 2。

## 审阅重点
- 不要出现超出年级的题,例如一年级出乘法。
- 没有时间压力的设计:计时只用于显示,不倒计时。
