# RD-10 课本关卡横屏改版(8 种题型)

> 先读 [README](../README.md) 第 1 节全局规则。

**依赖**:RD-02、RD-03、RD-04

## 目标
现有课本关卡 `LessonRunnerView` 换成横屏场景风格。判分、红心、连击、续学、报错、知识讲解等逻辑**一行都不改**,只改展示层和布局。

## 设计稿
设计稿只画了识字五步(RD-13)的关卡,这张卡是把同样的视觉语言用到课本题目上:
- HUD 参考 [03-l0.png](../design/png/03-l0.png):左上返回,右上奶油按钮组,左下 / 右下圆按钮。
- 题目卡片参考 [04-l1.png](../design/png/04-l1.png):白色厚卡,带彩色底部投影。
- 选项按钮参考 04-l1 右侧的组词按钮:奶油渐变,底部内阴影。

## 范围
### 1. 布局(舞台 844×390)
- **背景**:按学科取场景——数学 = 草地 + 小火车远景,语文 = 草地 + 小屋,英语 = 蓝天气球,科学 = 森林。同一节课背景固定。旧的「课程背景」装扮已下架(RD-07),不再生效。
- **顶部**(y=16):
  - 左:返回(退出确认沿用现逻辑);
  - 中:进度条——深色药丸里放一条橙色进度,替代 `StyledProgressBar`;右侧显示「3/8」;
  - 右:红心胶囊、设置(朗读、音效、自动播放三个开关,沿用 `settingToggle`)、帮助(打开知识讲解)。
- **主体**:左右两栏。
  - 左栏约 46% 宽:题干卡片,含题干文字、朗读按钮、图示(若有)。出战宠物站在卡片左下角,答对 / 答错时做反应。
  - 右栏约 54% 宽:作答区。
- **底部**:「检查」/「继续」大按钮在右下(`ClayButton .orange`)。
  - 反馈面板从底部滑出,覆盖底部约 34% 高度;答对用绿色系,答错用珊瑚色系;
  - 面板内容和现有 `feedbackPanel` 一致:正确答案、解析、朗读、报错入口。
- 横屏高度只有 390,**题干过长时左栏内部可滚动**,作答区不随之滚动。

### 2. 8 种题型的作答区
| 题型 | 横屏作答区 |
| --- | --- |
| 选择 `choice` | 2×2 网格奶油按钮;选项超过 4 个时改为单列可滚动 |
| 判断 `trueFalse` | 两个大按钮「对 ✓ / 错 ✗」左右并排 |
| 填空 / 计算 / 应用题 | 输入框 + 自带数字键盘(横屏下系统键盘会挡住一半屏幕,数学题用自绘 0–9、小数点、分数线、退格键盘,放在右栏) |
| 文字填空 `fillBlankText` | 系统键盘。键盘弹出时左栏题干收起成一行摘要,保证输入框可见 |
| 连词成句 `wordOrder` | 上方答案槽、下方词块,两区都在右栏 |
| 连线 `matching` | 左右两列,在右栏内 |

- 数字键盘按键 ≥ 52×52pt,ZCOOL 数字。
- 按 `QuestionRendererView` 的分发结构改各子视图,判分函数不动。

### 3. 其他关卡元素
- 课前讲解 `IntroCardView`:改为横屏卡片——左边讲解,右边宠物 + 「我知道了」。
- 红心用完 `OutOfHeartsGate`:改为横屏弹层,选项不变。
- 连击 `ComboOverlayView`、`XPFloaterView`:保留,换成 ZCOOL 字体和新配色。
- 报错表单 `reportSheet`:改为横屏 sheet。
- 跳级测试 `JumpTestView`、错题复习 `MistakeReviewRunnerView` 复用同一套关卡壳。这两处的改动包含在本卡。

## 不做
- 判分、经济、续学逻辑。
- 识字五步(RD-13)。

## 验收标准
- AC1 每种题型在 iPhone SE 和 iPhone 16 各一张截图(共 16 张),作答区完整可见、无遮挡。
- AC2 填空类题目在 iPhone SE 上打开键盘时,输入框和「检查」按钮都可见(截图)。
- AC3 现有 `LessonFlowUITests` 全部通过。为横屏更新的选择器在 PR 里列出。
- AC4 课前讲解、红心用完、连击、报错、退出确认、续学恢复,各附一张截图。
- AC5 判分、XP、星级与改版前一致:跑同一节课的固定答案序列,对比 `LessonOutcome`。用单元测试或 UI 测试证明。
- AC6 跳级测试和错题复习能完整走完。

## 审阅重点
- diff 中不应出现 `check(question:)`、`finish(lesson:)`、`persistSession()` 等逻辑函数的行为改动。
- 自绘数字键盘的无障碍:每个键都有 label,VoiceOver 能输入。
