# RD-19 睡前绘本

> 先读 [README](../README.md) 第 1 节全局规则。

**依赖**:RD-03 · **可并行**:RD-14、RD-15、RD-16、RD-17

## 目标
把现有的「故事」(`Features/Stories/StoryReaderView.swift`,数据是每本语文书的 `stories.json`)改成横屏绘本:大插画 + 带拼音的大字 + 朗读时逐词高亮。数据和奖励逻辑不变,只改界面,并加一个睡前模式。

## 设计稿
- [18-story.png](../design/png/18-story.png)

## 现状(开工前先读代码确认)
- `stories.json`:`{ id, bookId, unitNumber, unitTitle, storyIndex, title, language, sentences:[{text, audio}], questions:[…] }`。
- 插图:`BundledMedia/story-images/<bookId>/<storyId>-v2.jpg`,每个故事一张。
- 奖励:`Reading.id(.story, storyId)`,测验正确率 ≥ 0.8 给 15 XP,否则 5 XP(`Economy.storyQuizXp`)。**本卡不改这些。**

## 范围
### 1. 书架页(Dock「故事绘本」进入)
- 横屏书架:按单元分组,每本故事显示插图缩略图、标题、已读标记。
- 默认显示当前语文书的故事;顶部可以切换到其他语文书。
- 没有故事的书显示空状态。

### 2. 阅读页 `StoryBookView`(替换 `StoryReaderView` 的阅读阶段)
- **一句一页**:进度显示在标题缎带里,例如「小狐狸找月亮 · 3/8」。
- **背景**:
  - 现有插图铺满全屏,按比例裁切;
  - 插图上加一层由下往上的渐变,保证文字可读;
  - 插图缺失时,用 RD-03 的夜景场景兜底(设计稿那张)。
- **文字**:
  - 白色圆角底的大字,字号 ≥ 28pt;
  - 拼音用 ruby 排版(拼音在字上方),右上角「拼音 开 / 关」切换。
- **拼音来源**:
  - 构建时用 `pinyin-pro`(MIT)按句生成(新的 npm devDependency,只在脚本里用,PR 里说明),不在 App 运行时生成;
  - `stories.json` 是下载数据,不在仓库里,所以拼音写成旁挂文件 `content/story-pinyin/<bookId>.json`:`{ "<storyId>": [[句 0 每个字的拼音], [句 1 …]] }`,和字一一对应,标点为空串。seed 打包时一起带上,`DataLoader.loadStoryPinyin(bookId:)` 读取,找不到返回 `nil`(此时拼音开关隐藏);
  - 多音字报告列进 PR,人工复核。
- **朗读高亮**:「读给我听」播放该句录音,并逐字高亮。
  - 时间轴用录音时长按字数均分(第一版的近似做法,标点不占时间);
  - 有逐字时间戳数据之后,再改用精确时间。
- **翻页**:左右滑动,或点击屏幕两侧。
  - 「自动翻页」开关:读完一句等 1.5 秒,自动翻到下一页;
  - 最后一页之后进入现有的测验阶段,测验也换成横屏样式(复用 RD-10 的选择题组件)。
- **英语故事**(`language == "en"`):不显示拼音开关,用英文字体。

### 3. 睡前模式
- 书架页右上角「🌙 睡前模式」开关。打开后:
  - 背景压暗;
  - 自动朗读加自动翻页;
  - 跳过测验;
  - 读完一本自动停止,显示「晚安」页,屏幕亮度不调。
- 睡前模式读完**不发 XP**:它是听故事,不是阅读练习。PR 里写明这一点。

### 4. 计时
- 普通模式计入学习时长;睡前模式不计入。

## 验收标准
- AC1 阅读页和 18-story.png 对比一致(用 `chinese-g1up` 的第一个故事截图)。
- AC2 拼音旁挂文件由脚本生成并提交,seed 包更新,Swift 端能解码;某本书没有拼音文件时不崩,拼音开关隐藏。脚本校验每句拼音数组长度和字数一致。
- AC3 朗读高亮录屏(带声音)。
- AC4 测验奖励和改版前一致(单元测试或手测记录)。
- AC5 睡前模式完整读完一本的录屏。

## 审阅重点
- 插图在 SE 和 iPad 上的裁切不切掉主体。必要时为每张图加 `focus` 焦点坐标字段。
- 拼音的轻声、变调(一、不)按课本规则标注。
