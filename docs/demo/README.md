# 聪聪学堂 · 产品展示素材

2026-10-15 更新 Web 截图、README 主视觉及 38 秒产品短片。设计采用简洁排版、深绿与暖白底色、留白、柔和转场；不使用 Apple 商标、设备外形或现成发布会素材。

## 使用

- `congcong-demo.mp4`：1920×1080、30 fps、H.264/yuv420p、AAC，启用 faststart。仓库保存成片，不依赖另行发布的媒体链接。
- `poster.jpg`：点击观看的封面；`preview.gif` 是 9 秒轻量预览，完整影片以 MP4 为准。
- `congcong-demo.zh-CN.vtt`：中文说明字幕；画廊使用原生视频控件，默认不自动播放。
- `../web-showcase.html`：视频播放器、章节跳转及可点击放大的截图。从仓库根目录运行 `python3 scripts/media/preview_showcase.py`，访问 `http://127.0.0.1:3037/web-showcase.html`。本地服务支持视频字节范围，保证原生播放器可跳转章节；直接打开 HTML 也可查看图片。GitHub 不会执行仓库 HTML 中的脚本，README 因此直接提供图片和 MP4 链接。

## 真实画面与版本边界

原始截图位于 `../screenshots/web/`，交互过程的补充状态位于 `source/`。画面取自 `codex/ux-quality-repairs` 本地生产构建，基于代码提交 `acde104`，并在本轮加入保存退出与外观控件名称修复。演示使用新建的本地学习记录，不导入个人信息，不虚构学习成绩。

截图保留实际界面、文字、分数及布局。影片是多个真实操作状态的剪辑合成，不是连续录屏；界面外的通用显示边框、标题、背景和转场属于演示包装。手机画面是 CSS 视口模拟，不是真机拍摄。部分截图服务输出会裁去页面边缘，实际像素尺寸和 SHA256 以 `capture-manifest.json` 为准。

本分支尚未合并或上线，不能将影片描述为已发布版本，也不能据此声称教师、儿童或真机验收通过。README 的 iOS 图片保留历史素材标记，本轮没有重拍 iOS。

## 重制

需要 Python 3、Pillow、NumPy，以及包含 libx264/AAC 的 FFmpeg。脚本读取已经采集的截图，只重制包装与成片；不会访问浏览器或调用生成 API。

```sh
python3 scripts/media/build_showcase.py --stills-only
python3 scripts/media/build_showcase.py
```

默认使用本机 macOS 的 Hiragino Sans GB 与 Avenir Next；Linux 可安装 Noto Sans CJK 与 DejaVu Sans，或使用 `--cjk-font`、`--latin-font` 指定字体文件。系统字体不随仓库分发。背景配乐由渲染脚本本地合成，未采样第三方音乐，不含语音克隆；试听后可在播放器中静音。

成片核验包括完整解码、分辨率/帧率/时长、音量与黑场检查，以及每个镜头的抽帧目视检查。界面细节修复另核验普通退出保存草稿及已检查反馈，避免重复判分；不把媒体检查当作产品验收。
